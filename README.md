## À propos du bot
**NitroGen** génère des codes Nitro aléatoirement grâce à une suite de caractères **aléatoires**.  
Si vous avez de la **chance**, vous pourriez obtenir un code Nitro gratuit !

## Caractéristiques
- Détection de rôle pour :
    - **Tiers 1** : 1 minute de cooldown entre chaque message.
    - **Tiers 2** : 30 secondes de cooldown entre chaque message.
    - **Tiers 3** : 10 secondes de cooldown entre chaque message.
- Détection du statut Discord personnalisé, avec l'ajout d'un rôle **VIP**.
